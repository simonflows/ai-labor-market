# Искусственный интеллект и рынок труда

Интерактивный образовательный веб-проект, посвященный исследованию влияния искусственного интеллекта и автоматизации на рынок труда, трансформации профессий и ключевой роли гибких навыков (soft skills).

Демо-версия: https://simonflows.github.io/ai-labor-market/

## Описание проекта

Проект представляет собой интерактивный лонгрид, объединяющий аналитические данные отчета World Economic Forum («The Future of Jobs Report 2025») и практические инструменты для оценки профессий:

- Аналитика изменений: разбор баланса между сокращающимися и появляющимися рабочими местами к 2030 году.
- Каталог профессий: классификация специальностей на сокращающиеся, трансформирующиеся и растущие с динамической фильтрацией.
- Практикум по Soft Skills: карточки ключевых гибких навыков (критическое мышление, коммуникация, адаптивность) с рекомендациями по их развитию.
- Калькулятор «Индекс рутинности»: интерактивный расчет вероятности автоматизации задач на основе трех параметров (доля повторяющихся действий, объем живой коммуникации, частота нестандартных ситуаций).
- Интерактивный трекер: пошаговый план адаптации к меняющимся требованиям рынка с сохранением прогресса в браузере.

## Технологический стек

- HTML5: семантическая структура, мета-разметка, SVG-фильтры.
- CSS3: стиль Liquid Glass (стекломорфизм), CSS Grid, Flexbox, анимации и адаптивность под мобильные устройства.
- Vanilla JavaScript (ES6+): динамическая фильтрация, расчет индекса рутинности, сохранение состояния в LocalStorage.
- HTML5 Canvas: процедурная анимация звездного неба и интерактивный параллакс.

## Локальный запуск

Проект работает полностью на стороне клиента и не требует сборки:

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/simonflows/ai-labor-market.git
   ```
2. Открыть `index.html` в браузере или запустить локальный сервер:
   ```bash
   python -m http.server 8000
   ```
